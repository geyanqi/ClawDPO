# ClawDPO

ClawDPO 是一个由 Codex 编排的 DPO 迭代系统：它从脱敏业务对话中发现问题，让当前模型重新生成候选回复，构造高价值偏好对，启动训练，并在测试集上决定是否保留新模型。

```text
线上 badcase → 当前模型 rollout → 正确性初筛 → Codex 精选 pair
             → DPO 训练 → 新旧模型评测 → 保留更好的模型 → 下一轮
```

项目边界止于候选模型和评测报告，不负责发布或部署。v1 只训练单轮回复，不做多步 agent trajectory。
